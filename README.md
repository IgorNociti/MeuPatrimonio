# MeuPatrimonio
Reúna todos os seus investimentos em um só lugar e veja quanto cada um rendeu desde a aplicação até hoje. Conectado à bolsa via brapi.dev, acompanha ações, FIIs, ETFs, renda fixa, caixinhas e Tesouro Direto em tempo real, com gráficos simples da evolução do patrimônio. Funciona no computador e no celular.
